# Folder Animasi Lottie untuk Petugas Lapangan CivicLedger

Letakkan file animasi Lottie format `.json` di dalam folder ini:
- `loading.json`: Animasi saat memproses registrasi & login
- `verification.json`: Animasi saat menunggu persetujuan Admin
- `success.json`: Animasi saat berhasil login / aktivasi disetujui

Aplikasi telah dilengkapi fallback visual dinamis beranimasi, sehingga aplikasi tetap berjalan mulus dan estetis meskipun file Lottie belum ditaruh.
